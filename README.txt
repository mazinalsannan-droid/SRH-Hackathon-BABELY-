Babbly (web version)

Open index.html in a browser (double-click). No installation needed.

  index.html          the page and its pop-up sheets
  css/styles.css      the design (colours and fonts at the top)
  js/library.js       the Library math, Lock (AES-256) and Babble codes
  js/ai-fallback.js   built-in word swaps for Look-alikes and Lucky
  js/api.js           talks to the Babbly server when there is one
  js/ui.js            small helpers (sheets, toasts, copy)
  js/app.js           screens, tabs and buttons
  assets/             logo and favicon

Without the server it runs in guest mode on your device. Accounts and
sending to other Babblers need the server from babbly-app.zip.
